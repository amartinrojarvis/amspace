AMSpace 0.9.45 — Foco entre grupos de pestañas.

- Al seleccionar una pestaña, el foco queda en la ventana elegida aunque otro grupo tenga ventanas de la misma app. El otro grupo conserva su pestaña activa.
- El foco bajo el cursor respeta las barras de pestañas y no enfoca la ventana que queda debajo.

English

- Selecting a tab focuses the chosen window even when another group contains windows from the same app. The other group keeps its active tab.
- Focus follows mouse respects tab bars and does not focus the window underneath.

Universal Apple Silicon/Intel, macOS 13+. Firma ad hoc, sin Developer ID ni notarización / Ad hoc signed, no Developer ID or notarization.
